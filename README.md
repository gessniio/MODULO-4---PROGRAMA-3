# MÓDULO 4 - PROGRAMA 3

📌 Proyecto desarrollado para el Módulo 4 de programación.
Este programa tiene como objetivo aplicar conceptos fundamentales de programación, lógica y estructuras vistas durante el curso.

---

## 🚀 Descripción

El proyecto fue desarrollado utilizando programación estructurada/orientada a objetos (según corresponde al código del repositorio) y busca resolver una problemática específica mediana el uso de algoritmos y estructuras de control.

Entre las funciones principales del programa se incluyen:

* Manejo de datos mediante variables y estructuras.
* Uso de funciones y validaciones.
* Interacción con el usuario desde consola.
* Implementación de lógica de programación.
* Organización modular del código.

---

## 🛠️ Tecnologías utilizadas

* Lenguaje: C++
* IDE recomendado: Dev-C++, Code::Blocks o Visual Studio Code
* Compilador: g++
